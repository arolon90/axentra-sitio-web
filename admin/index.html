Solo para el equipo de AXENTRA. Cada persona entra con su propio token de GitHub: no hay contraseñas guardadas en la página.

¿Cómo obtengo mi token? (una sola vez)
  1. Entrá a GitHub con tu cuenta y abrí Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Tocá Generate new token. Nombre: Panel página AXENTRA. Vencimiento: el que prefieras (por ejemplo, 1 año).
  3. En Repository access elegí Only select repositories y marcá .
  4. En Permissions → Repository permissions, poné Contents en Read and write.
  5. Tocá Generate token, copiá el texto que empieza con github_pat_ y pegalo acá.

Guardá el token en un lugar seguro y no lo compartas: es tu llave para editar la página.
